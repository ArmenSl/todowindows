# Win11 Todo

A local Windows 11 desktop todo app in Python, Tkinter and SQLite. It was generated by the
[BESSER](https://github.com/BESSER-PEARL/BESSER) Spec-Driven Agent from a B-UML domain model and
one sentence: *"I want a todo app as windows 11 app"*.

## Features

- Tasks with priority (low to urgent), status, due date and description
- Complete, postpone, archive and delete tasks
- Several todo lists, tags, comments, reminders and file attachments
- Everything stored locally in SQLite; no sign-in, no network

## Quick start

Requires Python 3.10 or later. No external packages.

```powershell
python todo_app.py
```

Data is saved beside the application in `todo_app.db`.

## How it was built

| Path | What it is |
|------|------------|
| `buml/domain_model.py` | The B-UML domain model: 7 classes (TodoList, TodoItem, Tag, User, Reminder, Comment, Attachment) and 2 enumerations |
| `buml/diagrams.json` | The full BESSER editor project the app was generated from |
| `todo_app.py` | The generated application |
| `BESSER_GENERATION.md` | BESSER version and generator settings used |
| `.besser/`, `.besser_recipe.json`, `.besser_attribution.json`, `.agent-trace/` | What BESSER needs to continue from this repository ("Continue from GitHub"); keep them to iterate on the app in BESSER |

To change the app, open the model in the BESSER editor, or continue from this repository in BESSER
and describe the change to the Spec-Driven Agent.
